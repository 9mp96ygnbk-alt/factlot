FactLot's MCP server gives AI agents commercial real estate tools they can rely on: deterministic calculators that return every step and a versioned formula ID, lease-document verification, canonical IDs for parcels, entities and documents, and public-record facts that cite their source. The hosted server needs no API key.

Hosted MCP server details
Remote URL https://api.factlot.com/mcp
Transport Streamable HTTP, stateless
Authentication None on the free tier (60 requests a minute per IP address). Paid plans send Authorization: Bearer <key>.
Registry name io.github.9mp96ygnbk-alt/factlot in the official MCP Registry
Tool annotations Every tool is read-only and has a title
Licence Apache-2.0 (server and calculators), MIT (schema and SDKs). The same server runs locally or in Docker.

Check the connection

The server answers a plain JSON-RPC initialize request, so you can test it without a client: 

curl -s https://api.factlot.com/mcp \
  -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"check","version":"1"}}}'

The reply names the server and carries its instructions: which tool to use for which task, and how to cite the result.

What the tools do

  • Calculators (calc_*): lease economics, CAM, debt sizing, prepayment, ASC 842, valuation, returns, waterfalls, 1031 timing, hotel and multifamily metrics. Each returns the value, every intermediate step with its formula, warnings, and a versioned formula ID. See the calculator pages.
  • Document verification (doc_*): the agent extracts a lease term with its verbatim quote and page; FactLot checks that the quote is on that page and states the value, and returns a cited fact or the reason it could not. No model runs on FactLot's side and nothing is stored.
  • IDs and facts (id_*, fact_*): deterministic IDs for parcels, entities, buildings, spaces and documents, and cited fact packages a counterparty can check.
  • Rules (rules_*): the Texas property tax protest deadline, with statute citations.
  • Lease comps and registry: 6,994 federal (GSA) lease comps on the hosted server; the registry_* parcel and owner lookups cover Maryland, the District of Columbia, Juab and Summit counties in Utah, and Harris, Dallas, Travis, Collin, Denton and Williamson counties in Texas (349,869 parcels). Tarrant County is not served by the hosted registry while the publisher's terms for AI use are unclear. Other regions run on a self-hosted copy with a registry file.
  • Discovery: search, fetch and schema_get help an agent find the right tool.

Agent frameworks

LangGraph and LangChain (langchain-mcp-adapters), the OpenAI Agents SDK, CrewAI, the MCP Python and TypeScript SDKs and the Vercel AI SDK connect with their standard MCP clients. The framework guide has tested recipes: loading only some tools, backing off on HTTP 429, naming your client, and sending a key.

Limits

  • The free tier allows 60 requests a minute per IP address. Every HTTP request counts, including initialize and tools/list; cache the tool list.
  • Registry lookups are on every plan, metered by plan: 25 a day per IP address on the free tier, 5,000 a month on Pro and 100,000 a month on Team. A lookup is one answered call to a registry_ tool. registry_coverage, coverage misses (a county or system that is not loaded) and input errors are not counted. Call registry_coverage first: it lists what is hosted. The coverage page lists what the registry holds and the downloadable samples.
  • Calculators check their inputs and return warnings; they do not replace professional judgment on lease terms, valuation or tax positions.
