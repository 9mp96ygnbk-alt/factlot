FactLot's MCP server gives AI agents commercial real estate tools they can rely on: deterministic calculators that return every step and a versioned formula ID, lease-document verification, canonical IDs for parcels, entities and documents, and public-record facts that cite their source. The hosted server needs no API key.

Hosted MCP server details
Remote URL https://api.factlot.com/mcp
Transport Streamable HTTP, stateless
Authentication None on the free tier (60 requests a minute per IP address). A Pro, Team or free key is sent as Authorization: Bearer <key>.
Registry name io.github.9mp96ygnbk-alt/factlot in the official MCP Registry
Tool annotations Every tool has a title and is read-only, except the hosted report_create, which builds a file and keeps it for 24 hours
Licence Apache-2.0 (server and calculators), MIT (schema and SDKs). The same server runs locally or in Docker.

Check the connection

The server answers a plain JSON-RPC initialize request, so you can test it without a client: 

curl -s https://api.factlot.com/mcp \
  -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"check","version":"1"}}}'

The reply names the server and carries its instructions: which tool to use for which task, and how to cite the result.

What the tools do

  • Calculators (calc_*): lease economics, CAM, debt sizing, prepayment, ASC 842, valuation, returns, waterfalls, 1031 timing, hotel and multifamily metrics. Each returns the value, every intermediate step with its formula, warnings, and a versioned formula ID. See the calculator pages.
  • Document verification (doc_*): the agent extracts a lease term with its verbatim quote and page; FactLot checks that the quote is on that page and states the value, and returns a cited fact or the reason it could not. No model runs on FactLot's side and nothing is stored.
  • Reports (hosted only): report_create builds an XLSX workbook, a PDF or an ICS calendar from a tool result, by code with no model. It returns a download link that works 24 hours, after which the file is deleted. 3 a month free per IP address, 50 on Pro, 1,000 on Team. See the reports guide.
  • IDs and facts (id_*, fact_*): deterministic IDs for parcels, entities, buildings, spaces and documents, and cited fact packages a counterparty can check.
  • Rules (rules_*): the Texas property tax protest deadline, with statute citations.
  • Lease comps and registry: 6,994 federal (GSA) lease comps on the hosted server; the registry_* parcel and owner lookups cover Maryland (all 24 jurisdictions), the District of Columbia, Juab and Summit counties in Utah, sixteen Texas counties (Harris, Dallas, Travis, Collin, Denton, Williamson, Cameron, Nueces, Galveston, Jefferson, Brazos, Midland, Ector, Grayson, Guadalupe and Kaufman), New York City (all five boroughs), Los Angeles County, San Francisco, the City of Boston, Denver, and Connecticut (statewide, by town) (891,631 parcels in 60 counties). Tarrant County is not served by the hosted registry while the publisher's terms for AI use are unclear. Other regions run on a self-hosted copy with a registry file.
  • Discovery: search, fetch and schema_get help an agent find the right tool.
  • Resources (hosted server; the local server gains them in its next release; read-only, no key, no registry lookup): factlot://coverage (what the hosted registry serves, by place), factlot://sources (every reviewed source with its licence, AI use, redistribution and attribution), factlot://markets (a worked example per hosted market), factlot://schemas/tools, factlot://schemas/fact, factlot://spec/id and factlot://plans, plus one factlot://coverage/{place} per hosted place and one factlot://markets/{slug} per hosted market in the resource list, and factlot://sources/{source_id} and factlot://schemas/tools/{tool} by name.
  • Prompts (hosted server; the local server gains them in its next release): property_owner, owner_portfolio, parcel_value_history, tx_unequal_appraisal_candidates, lease_abstract_check and deal_math, each giving the tools to call in order and asking for every fact to be cited.

Agent frameworks

LangGraph and LangChain (langchain-mcp-adapters), the OpenAI Agents SDK, CrewAI, the MCP Python and TypeScript SDKs and the Vercel AI SDK connect with their standard MCP clients. The framework guide has tested recipes: loading only some tools, backing off on HTTP 429, naming your client, and sending a key.

Limits

  • The free tier allows 60 requests a minute per IP address. Every HTTP request counts, including initialize and tools/list; cache the tool list.
  • An optional free key by email is sent as Authorization: Bearer <key> like a paid key, but it is a free caller: the Free plan rules and no paid tools. Its requests and registry lookups count per key, with all the free keys used from one IP address sharing one minute limit and daily cap; its reports still count per IP address too.
  • Registry lookups are on every plan, metered by plan: 25 a day per IP address on the free tier, 5,000 a month on Pro and 100,000 a month on Team. {{PLAN_LOOKUP_COUNTED}} {{PLAN_PAID_ONLY}} Without such a key, a refused registry call answers PlanRequired and counts nothing, and a shortened answer says what was left out; both link the pricing page. Call registry_coverage first: it lists what is hosted. The coverage page lists what the registry holds and the downloadable samples.
  • Calculators check their inputs and return warnings; they do not replace professional judgment on lease terms, valuation or tax positions.
