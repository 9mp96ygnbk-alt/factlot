Where FactLot holds whole-county commercial property data. Only the counties marked hosted answer on the hosted API ({{COV_N_HOSTED}} counties); the others are built in the open-source pipeline and answer only on a self-hosted FactLot. Grey means not usable yet: not reviewed, not loaded, waiting on publisher terms, a sample only, or too old.

What the colors mean

  • Hosted lookups. Served by the hosted API at api.factlot.com on every plan, metered by plan, including the free tier. Call registry_coverage to list what is hosted. The counts and dates are those of the data the API answers from. Suffolk County is hosted for the City of Boston only. DC's data is also published as an open sample database (CC BY 4.0) you can run with the FactLot MCP server.
  • Open-source pipeline only, audited. Built in the open-source pipeline, not on the hosted API: a lookup on api.factlot.com answers that the county is not loaded. The whole county's commercial roll was built from a source whose terms are recorded and verified, and an audit re-read the publisher's archived file and found the registry file holds exactly its in-scope parcels. To query it, build the registry file and run FactLot yourself.
  • Open-source pipeline only, not audited. Built in the open-source pipeline, not on the hosted API, from a verified source with a per-county count and a data date in the review record; the audit has not covered it yet. To query it, build the registry file and run FactLot yourself.
  • Not usable yet. Everything else, including statewide loads with no per-county count, partial or sample loads, sources whose terms are still open, and data more than {{COV_MAX_AGE}} days old.

Hosted lookups are open now for the counties marked hosted: Maryland (all 24 jurisdictions), the District of Columbia, Juab and Summit counties in Utah, sixteen Texas counties (Harris, Dallas, Travis, Collin, Denton, Williamson, Cameron, Nueces, Galveston, Jefferson, Brazos, Midland, Ector, Grayson, Guadalupe and Kaufman), New York City (all five boroughs), Los Angeles County, San Francisco, the City of Boston, Denver, and Connecticut (statewide, by town). Tarrant County is not served by the hosted registry while the publisher's terms for AI use are unclear. To ask for another county, email us.

Method and sources
  • Every county is keyed by its 5-digit Census FIPS code. Counts are quoted from the registry's review records and checked by the generator; nothing is estimated.
  • The registry is built to keep owners that are organisations and to exclude natural persons' names. If a record names you as a person, or is wrong, email contact@factlot.com and we will remove or correct it.
  • The freshness limit is {{COV_MAX_AGE}} days before {{COV_ASOF}}, the latest source review date.
  • Machine-readable file: /coverage/counties.json (status by county) and /coverage.json (the hosted places with counties, parcel counts, as-of dates, sources with licence, AI-use and redistribution status, ID systems and the tools that answer there). Full per-source terms and records: registry coverage.
  • Boundaries: US Census Bureau cartographic boundary files (public domain), via us-atlas.
