# Texas Public Information Act requests

Use a request when an appraisal district doesn't publish a bulk download, when its terms are
unclear, or to get a complete certified roll on the record. The legal basis is Texas Government
Code chapter 552.

Before sending a request:

- **Find the right office.** Each appraisal district names an officer for public information
  requests on its website, often on a page titled "Public Information" or "Open Records".
  Send the request to that officer.
- **Be ready for charges.** Districts may charge for programming or copying under Gov't Code
  §552.261 and following, and must send an itemized estimate when the cost exceeds $40. Our budget
  is $0, so the letter asks for existing electronic files and a cost estimate before any charges.
- **Know the timeline.** A district must respond promptly. If it can't produce the records within
  10 business days, it must say when it will.
- **Some information is withheld.** Confidential owner information is withheld under Tax Code
  §25.025. The letter says explicitly that we don't want it.

## Template

> **Subject:** Public Information Act request: appraisal roll data export (tax year [YEAR])
>
> To the Officer for Public Information, [APPRAISAL DISTRICT NAME]:
>
> Under the Texas Public Information Act (Tex. Gov't Code ch. 552), I request a copy of the
> following existing records, in their existing electronic format (for example CSV, fixed-width
> text, or a database export), delivered by email or download link:
>
> 1. The [certified / most recent supplemental] appraisal roll for tax year [YEAR] for real
>    property in [COUNTY] County, including for each account: account number, parcel or
>    geographic ID, situs address, owner of record name and mailing address, State Property Tax
>    Code category, land area, improvement area, year built, and market and appraised values.
> 2. The record layout or data dictionary that describes those files.
>
> Please exclude any information that is confidential under Tex. Tax Code §25.025 or other law.
> I do not seek it.
>
> If producing these records will involve any charge, please send an itemized estimate before
> proceeding, as provided by Gov't Code §552.2615. If the records are already available for
> download, a link is sufficient.
>
> The records will be used in FactLot, a property-data service that cites the appraisal district
> as the source of every fact.
>
> Thank you,
> [NAME]
> [ORGANIZATION], [EMAIL], [PHONE]
