(and 71 other Wisconsin counties) in one review** (gated on terms since the rights review of 2026-11-06: the publisher states no licence); the IndianaMap statewide layer has no owners or values (Marion County's own layer is used); Ohio, Michigan, Illinois and Missouri have no statewide parcel file with owners, so each county was
reviewed on its own. Counts are from real runs on the real files, loaded into a scratch registry (scratch only; nothing was written into a shared registry file).

## Adapters and tests written

`wi_statewide`, `in_marion`, `mi_oakland`, `oh_cuyahoga`, `oh_franklin` (in `python/src/factlot/registry/adapters/`) with `python/tests/test_adapter_<module>.py` for each: 5, 5, 4, 4 and 6 tests, all passing (`cd python && PYTHONPATH=src python3 -m unittest tests.test_adapter_<module>`).
The ArcGIS adapters read the collector's archived `f=json` pages from a collector directory (`collected/<id>`), one snapshot per page; the sources are class-filtered extracts, so no run retires parcels. No adapter was written for gated sources without a seen layout (Hamilton, DuPage, Lake, Will, Macomb, St. Louis County, Jackson) or for
the entity registers (none obtainable).

## Findings that apply beyond this region

- **Michigan:** Oakland differs sharply from Wayne. Its open-data terms grant reuse "for any lawful purpose" (Wayne's portal terms limit saved materials to personal, non-commercial use), but its open layer has no owner names. Macomb states no terms and has owners but no property class.
- **Terms:** three counties with free services bar redistribution without permission or reserve all rights (DuPage, Will, St. Louis County); three state no terms at all (Cuyahoga, Franklin, Macomb); Lake's terms could not be read. One policy decision on "public record, free download, no terms stated" (Franklin, Cuyahoga) unlocks 34,280 Cuyahoga parcels immediately and the full Franklin file once it runs from GitHub.
- **Multifamily:** Wisconsin and Michigan have no multifamily class (apartments are commercial), so Milwaukee and Oakland loads have B = 0; Ohio (401-403, Cuyahoga 4010-4090) and Indiana (401-403) identify apartments.
- **Redistribution of ArcGIS-hosted data:** archiving paged JSON from a public REST layer (maxRecordCount 1000-2000) works for the collector and keeps a hashed snapshot per page; every such source is a class-filtered extract and should be refreshed monthly.
- **Hosts that block automated clients** (not worked around): ohiosos.gov, inbiz.in.gov (robots.txt), lakecountyil.gov, stlouiscountymo.gov, and hcauditor.org by robots.txt for `/download/`.
