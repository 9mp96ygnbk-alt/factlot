# Decision: cited facts from public files (2026-11-06)

Robert decided on 2026-11-06 that FactLot may keep and redistribute **cited commercial facts** from a publisher that releases a public file but does not grant redistribution in writing.

This decision covers the terms-gated public files already reviewed for that gap:

- `pa-philadelphia-opa`
- `il-cook-assessor`
- `ga-fulton-assessor`
- `fl-dor-nal`
- `mi-wayne-parcels`
- `va-fairfax-assessor`
- `ca-riverside-assessor`
- `ca-san-bernardino-assessor` (no adapter yet; nothing is ingested until one exists)

It does not cover:

- a paid extract or subscription (`nv-clark-assessor`, secretary-of-state bulk products, and any other purchase gate)
- a click-through acknowledgement that has not been accepted (`wa-king-assessor`)
- a host that blocks automated clients (do not work around the block)
- Arizona's commercial-purpose statement (`az-maricopa-assessor`, A.R.S. 39-121.03)
- an unlisted table the publisher sells as the roll (`ca-alameda-assessor`)

The publisher's own wording is unchanged. Where that wording limits use to personal or internal use, this decision is the registry's basis for cited facts, and the source record must keep the publisher's words beside it. Natural-person names are still not stored. No fee is paid. A source stays unverified until a real download confirms the file URL.

Counts from a new staging run are not live, and they are not a national total.
