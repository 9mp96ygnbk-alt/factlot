Subject: Virginia Freedom of Information Act request — real-estate assessment owner-of-record file (commercial parcels)

Under the Virginia Freedom of Information Act, Va. Code § 2.2-3704, I request the existing electronic owner-of-record file for Fairfax County real-estate assessments.

The county publishes Tax Administration assessment tables on its GIS Hub at https://data-fairfaxcountygis.opendata.arcgis.com/ . The published tables include Parcels Data, Legal Data, Assessed Values, Land Data, Commercial Data, Sales Data, Dwelling Data, and Dwelling Addition Data. None of those tables has an owner-of-record column. Please provide the existing owner table, or other existing file, that states the owner of record for each parcel, keyed by the tax-map parcel identifier (PARID), and the record layout that describes it.

Please limit the copy to commercial parcels. If separating commercial parcels would require the county to create a new record, the existing owner file is enough. FactLot will keep commercial parcels only.

FactLot is an open registry of cited facts about commercial parcels. The registry will not store or index a natural person's name. A parcel owned by a person may be kept without the name.
