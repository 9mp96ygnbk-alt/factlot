ArcGIS Hub is footnote 85:

> Software licenses and subscriptions included with ArcGIS Hub may only be used to support the

> community initiatives enabled by ArcGIS Hub. Customer may allow 3rd parties to be Named Users of

> ArcGIS Hub for the sole purpose of engaging in community activities. Customers may allow employees,

> other use of software licenses and subscriptions included with ArcGIS Hub is permitted.

Footnote 7 on the same PDF is an ArcGIS Pro named-user limit. It is not a rule about downloading a county's open data. It was not needed for the Hub question.

E300 binds the Esri customer who licenses the named products. Footnote 85 limits how that customer may use the software licences included with ArcGIS Hub. It is silent on redistribution of a publisher's public records and silent on commercial use of open data a county has already published. It would restrict FactLot only if FactLot were the Hub customer using those included licences for something other than the community initiative.
