## What to host for these directories

Submit an endpoint that serves only the keyless tools: calculators, IDs, the Texas rule, `fact_validate`, `search`, `fetch` and `schema_get`. Leave the six `registry_*` tools off (do not set `FACTLOT_REGISTRY_DB`) and do not set an API key. Reasons: the tools are pure computation with no private data; Anthropic asks for OAuth 2.0 for authenticated services and "no authentication for public data" otherwise; OpenAI's portal "supports no authentication, OAuth, or mixed access" and does not support API-key or bearer-token flows. The registry becomes a separate, authenticated offering later and must not be described as available here.

Both platforms require that every tool carry a title and a read-only or destructive annotation. Checked 2026-11-03 against the built local server: all 24 tools carry a title and `readOnlyHint: true`. Re-check the hosted server with `tools/list`.

## ChatGPT apps directory

- **Where:** the OpenAI developer dashboard, [platform.openai.com/plugins](https://platform.openai.com/plugins) ([docs](https://developers.openai.com/apps-sdk/deploy/submission), read 2026-11-03). Older write-ups call it `apps-manage`; use whichever the live dashboard shows.
- **Prerequisites (from the docs):** organisation verification (individual or business); a stable public HTTPS endpoint (one MCP server per plugin); domain verification by serving a token as plain text at `https://<host>/.well-known/openai-apps-challenge`; HTTPS website, support, privacy policy and terms URLs; a square logo and composer icon (at least 48x48); five positive and three negative test cases; an accessible walkthrough video URL; release notes; reviewer credentials only if sign-in is needed.
- **Package:** the portal takes a ZIP that includes the MCP server configuration; the docs do not describe the ZIP's layout on the page read, so follow the dashboard's validation errors.
- **Text:**
  - Name: `FactLot`. Subtitle/short description: the 94-character one-liner.
  - Description: the long description, edited as above.
  - Example prompts for the five positive tests: "Reconcile 2026 CAM for this tenant: 12,000 sf of a 100,000 sf building, base year 2024, 5% cumulative cap, [paste figures]"; "Compare these two office proposals for my client: [paste]"; "How large a loan can $1,000,000 NOI support at 6% over 30 years with a 65% LTV cap?"; "What is the WALT of this rent roll?"; "Give me the FactLot ID for parcel number 5432-001-012 in Los Angeles County." Run each against the hosted endpoint before submitting and keep the real outputs.
  - Negative tests (the app should not be used): "Who owns 1600 Pennsylvania Avenue?" (no registry on this endpoint); "Tell me the best tenant to sign"; "Draft a lease". Describe the expected behaviour as "the app is not called, or returns an input error."
