**Title:** Welcome to FactLot: start here

```
Thanks for looking at FactLot. This is the public place to ask questions, share what you are building, and report where an agent got something wrong.

**What FactLot is.** An open fact layer for commercial real estate AI agents: 14 deterministic calculators with audit trails and versioned formula IDs, stable IDs for parcels, entities, spaces and documents, a fact schema with provenance and AI-use rights, and a registry of cited public-record facts. Details: README.md and llms.txt.

**Try it today.** It is not on npm or PyPI yet, so install from GitHub. The commands are in the README ("Quick start"). The local MCP server needs no API key.

**What is not done.** No hosted endpoint, so the registry cannot be queried by the public yet. Registry coverage is uneven (see docs/registry/sources/README.md). Lease ingestion is a prototype. FactLot Bench exists but has not been run on current models, so there is no result to quote. The 165-persona survey in the docs is simulated.

**Where to post what.**
- Questions and how-do-I: here, in Q&A.
- A calculator gave a wrong number, an ID collided, a registry fact is wrong: open an Issue, with the inputs and the expected value and where it comes from. Wrong numbers are the most useful reports we can get.
- Want to build on it or add a calculator or a source: read CONTRIBUTING.md and AGENTS.md first.
- Show what you built: Show and tell.

**Hosted registry early access.** If your team wants cited parcel-to-owner-to-entity lookups without self-hosting, email contact@factlot.com. The hosted service is not public yet, and early-access teams will help set pricing.

Please do not paste confidential leases or personal data into public posts or issues.

I'm the maintainer and I read everything.
```
