## Bugs and confusions (count of agents)
    1  lease ingestion is built for executed leases, not proposal pdfs or email redlines, so all five term sheets had to be hand-keyed before the first calculator call
    1  usf-quoted proposals had to be converted to rsf outside factlot with a guessed load factor, so the comparison inherits an uncited input
    1  must build from source; nobody at a 12-person shop maintains a typescript build
    1  the brief does not say whether calc_compare_proposals amortizes ti the way our excel template does, so reconciling to the penny is unverified
    1  inland empire, savannah and lehigh valley all return registryunavailable or empty results, so three of four markets are zero before any filter runs
    1  no oauth and a single shared bearer key means the hosted server fails our sso and security review on the first question
    1  no soc 2 and no usage metering, so procurement cannot attribute cost to a client engagement
    1  ground-truth spec verification flags, the thing we asked for, do not exist because specs do not exist
    1  every registry call for a phoenix address returns registryunavailable until i load a database that does not exist for arizona
    1  building from source is beyond a 3-broker firm with free crexi tiers; the python sdk being dependency-free helps only if someone can run it
    1  the entity model is keyed to a registry file number, which does not help me answer whether an llc belongs to a health system
    1  calling the only rules tool for a nashville pad is nonsensical; it answers a texas protest deadline question i did not ask
    1  all registry tools return registryunavailable for the southeast
    1  the privacy stance against inferring anything about people is correct for us legally, but it also means the pad-owner reach problem is out of scope by design
    1  most of the 38 leases are scanned; without ocr the ingestion prototype cannot read them, so the audit trail covers only the born-digital minority
    1  renewal rent formulas like 95 percent of fmv per arbitration are free text that the basic predicate set does not model
    1  a quote can be found on the page while the value misreads it, and nothing catches that, which is fatal for a 98 percent critical-date bar
    1  it has only been run on one synthetic lease, so there is no accuracy number to put in front of the client
    1  no soc 2 and a single shared bearer key rule out the hosted path entirely; self-host is the only option
    1  the registry schema stops at area and year built, which is a generic office schema by any lab standard
    1  every cambridge address returns registryunavailable
    1  i ran calc_debt_sizing with estimated inputs and got a precise, well-stepped answer to a question built on guesses, which is more dangerous than no answer
    1  calc_compare_proposals is lease-shaped ($/sf/yr); forcing $/kw/mo colo quotes through it produces a ranking whose units mean nothing to the client
    1  history starts 2026-11-02 with one snapshot, so the monthly changes i track in county minutes are invisible
    1  three of four markets return registryunavailable
