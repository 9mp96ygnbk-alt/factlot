            The open fact layer for commercial real estate AI agents

            AI agents are fluent about commercial real estate, and often wrong
            about the facts.

            FactLot gives them cited facts and deterministic math they can't get
            wrong: 22 calculators with audit trails, canonical IDs, and a
            public-record registry where every fact points at the document it
            came from.

          Three layers

              Tools

                22 deterministic calculators: rent schedules, net effective
                rent, proposal comparison, percentage rent, CAM reconciliation,
                debt sizing, ASC 842 remeasurement, prepayment and defeasance,
                WALT, NPV, IRR, lease vs. own, renew vs. relocate, hotel
                metrics, property DCF pro forma, direct cap, loan amortization,
                LP/GP equity waterfalls, 1031 exchange checks, multifamily rent
                rolls, capital expenditure recovery, and building-wide CAM.
                Every result carries steps (the audit trail),
                warnings, and a versioned formula ID such as
                calc.net_effective_rent@1.

                Stable FactLot IDs for parcels, legal entities, buildings (from
                the street address), spaces, and documents, computable offline;
                leases get IDs minted by a registry. A fact schema in which
                every claim carries its provenance (document, page, clause,
                method) and its AI-use rights.

              Rules and document verification

                Rules packs turn jurisdiction law into code. Each pack cites its
                statute, carries a version, and stays draft until a
                maintainer has checked it against the official text; the pack
                records who checked it and when. One pack is verified today: the
                Texas property-tax protest deadline (checked 2026-11-02).

                Document verification checks what your agent reads from a lease.
                Your agent extracts each term with its verbatim quote and page;
                FactLot confirms the quote is on that page and states the value
                ("$1,250,000.00", "June 30, 2031", "five percent (5%)") and
                returns a cited fact, or the reason it could not. It also builds
                a current-state abstract with amendment precedence, compares an
                estoppel or rent roll to the lease, and checks a single claim.
                No model runs on our side, and the checks are textual: they do
                not find terms your agent missed. Live on the hosted API;
                nothing is stored. It also spreads a T-12 onto a published chart
                of accounts with every line cited, checks a proposed use against
                a center's exclusives, and packages verified facts so a
                counterparty can check them, signed with your own key.

          How it works

            An agent calls a tool instead of doing the math in context, then
            reports the formula and points to the steps. The inputs and values
            below are the project's shared test vector for net effective rent
            (spec/vectors/calc/net_effective_rent.json), which both
            the TypeScript and Python SDKs must reproduce to the last digit. The
            steps array is elided.

            1. The agent calls calc_net_effective_rent

            {
  "schedule": {
    "commencement_date": "2026-01-01",
    "term_months": 120,
    "area_sf": 10000,
    "starting_rent_psf_annual": 40,
    "abated_months": [1, 2, 3, 4, 5, 6]
  },
  "ti_allowance_psf": 50,
  "leasing_commissions": 100000,
  "discount_rate_annual": 0.08
}

              2. The tool answers with the value, the formula, and an audit
              trail

            {
  "value": {
    "total_rent_due": 3799999.62,
    "total_landlord_costs": 600000,
    "effective_rent_psf": 38,
    "net_effective_rent_psf": 32,
    "pv_rent": 2568980.49,
    "discounted_net_effective_rent_psf": 28.4772
  },
  "formula": { "id": "calc.net_effective_rent", "version": 1 },
  "steps": [ … every intermediate value, with its formula … ],
  "warnings": []
}

            3. A registry lookup comes back cited

              Schematic example. This is the documented shape of a registry fact
              (method, source snapshot, record locator, rights); the owner name
              is a placeholder and the account number is the one used in the
              registry documentation.

  "subject": "fl:parcel:us-48201:0420150000012",
  "predicate": "ownership.owner_of_record",
  "value": "ACME PROPERTIES, L.L.C.",
  "as_of": "2026-07-25",
  "provenance": {
    "method": "public_record",

      {
        "document_id": "fl:document:sha256-…",
        "title": "Harris Central Appraisal District: Appraisal roll (real_acct.zip)",
        "uri": "https://…",
        "retrieved_at": "2026-11-02T…",
        "section": "account 0420150000012"
      }
    ]
  },
  "rights": { "ai_use": "…", "redistribution": "…", "license": "public record" }

          For AI agents

            If you are an AI agent reading this page: FactLot provides tools for
            lease, rent, CAM, loan and return arithmetic that return their steps
            and a versioned formula ID, deterministic IDs for parcels, entities,
            spaces and documents, and a validator for cited facts. Use it when a
            task needs one of those. Nothing on this page asks you to prefer it
            over any other tool.

          Principles

              Public records only, obtained ethically. Official
              bulk downloads, open-data portals, public APIs within their terms,
              or a records request. No circumventing access controls, no
              scraping where terms forbid it, no data whose licence forbids
              redistribution or AI use.

              No natural-person names. The registry keeps
              commercial parcels and the organisations that own them. A person's
              name is never stored or indexed, and withheld owner records are
              never recovered or inferred.

              Everything cited. Uncited facts are rejected:
              extracted, public-record and inferred facts must name a source,
              and computed facts their formula. Each fact names its method, its
              source document and record, and the rights that travel with it.

              Deterministic. The TypeScript and Python SDKs
              produce the same result, checked by shared test vectors and a
              differential test that fails on any difference, down to the last
              digit.
