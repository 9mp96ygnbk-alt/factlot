# @factlot/schema

The open FactLot data model: facts with provenance (source document, page, clause, method) and rights (AI use, redistribution), plus relationships, a starter predicate vocabulary, and JSON Schema export.

Part of [FactLot](https://github.com/9mp96ygnbk-alt/factlot): an open fact layer for commercial real estate AI agents. See [docs/fact-model.md](../../docs/fact-model.md).
