# @factlot/id

FactLot ID: canonical identifiers for parcels, legal entities, buildings, spaces, leases, loans, and documents. IDs are deterministic wherever a natural key exists, so any agent can compute them offline.

Part of [FactLot](https://github.com/9mp96ygnbk-alt/factlot): an open fact layer for commercial real estate AI agents. See [docs/id-spec.md](../../docs/id-spec.md).
