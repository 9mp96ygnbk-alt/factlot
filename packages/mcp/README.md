# @factlot/mcp

An MCP server exposing FactLot calculators, IDs, and fact validation to any MCP-capable agent. It runs locally over stdio, needs no API key, and makes no network calls.

Part of [FactLot](https://github.com/9mp96ygnbk-alt/factlot): the open fact layer for commercial real estate AI agents. Run with `npx -y @factlot/mcp` once published, or `node packages/mcp/dist/bin.js` from a source build.
