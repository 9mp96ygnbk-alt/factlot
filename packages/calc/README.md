# @factlot/calc

Deterministic, traceable CRE calculators: rent schedules, net effective rent, CAM reconciliation (with explicit cap methods), loan sizing, WALT, NPV, and IRR. Every result includes `steps` (an audit trail), `warnings`, and a versioned `formula` ID.

Part of [FactLot](https://github.com/9mp96ygnbk-alt/factlot): the open fact layer for commercial real estate AI agents. Agents should call these instead of doing lease or loan math in context.
